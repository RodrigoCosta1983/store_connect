de sessão; não foi usado como prova positiva de endpoint atual.

databaseId públicos mutáveis, configuração antes do uso e tratamento Web próprio.
cloud_firestore_web/lib/cloud_firestore_web.dart -> src/interop/firestore.dart
-> src/interop/firestore_interop.dart, chegando a connectFirestoreEmulator.

dessas fontes não comprova destino vivo, Source.server ou autorização de Rules.
